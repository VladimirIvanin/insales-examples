# Как использовать примеры

[Каталог примеров](../README.md) · [Навык insales-coder](https://github.com/VladimirIvanin/insales-coder)

1. Выберите рецепт и прочитайте строку «Где использовать»: объект `product`, `collection`, `article` или `cart` доступен в соответствующем контексте шаблона.
2. Скопируйте Liquid и HTML в шаблон либо сниппет. Стили и JavaScript можно разместить рядом с разметкой или в файлах темы. Liquid в отдельном статическом `.js` не обрабатывается: передавайте данные через HTML-атрибуты или скрипт внутри Liquid.
3. Подключите перечисленные зависимости в теме, если их ещё нет. Для common.js v2 нужны сама библиотека и её зависимости темы; не подключайте второй экземпляр. Наличие jQuery не означает наличие глобального Lodash.
4. Замените демонстрационные тексты и адреса категорий. Проверьте пустые данные, доступность элементов с клавиатуры и результат на разных ширинах экрана.

Примеры рассчитаны на темы с common.js v2 там, где он указан. Механизмы, основанные на его атрибутах, должны инициализироваться самой темой; для динамически добавленных карточек используйте `Products.initInstance`. Для новой темы поколения 4 см. [описание шаблона](https://docs.liquidhub.ru/4%20поколение/Шаблон/). [Заготовки приложений InSales](../README.md#заготовки-приложений-insales) перечислены в основном каталоге.

Каждый пример ограничивает собственную разметку контейнером. При удалении и повторном создании интерактивного блока в приложении с собственным жизненным циклом дополнительно управляйте отпиской от глобальных событий и освобождением ресурсов.
