# Утилиты

[На главную](../../README.md) · [Как использовать примеры](../../docs/usage.md)

- [Склонение слова по количеству](declension.md) — Выбирает форму «товар», «товара» или «товаров».
- [Одинаковая высота карточек](equal-height.md) — Выравнивает элементы внутри одной строки без вычисления отступов.
- [Извлечь изображения из HTML](extract-images.md) — Возвращает адреса изображений, содержащихся во входной HTML-строке.
- [Прогресс загрузки изображений](image-progress.md) — Отслеживает загрузку и ошибки изображений и вызывает функцию с текущим состоянием.
- [Просмотр объекта](inspect-object.md) — Безопасно выводит объект в консоль браузера.
- [Определение местоположения](location.md) — Запрашивает приблизительное местоположение и позволяет сохранить результат на время сеанса.
- [Группировка характеристик и скидка](parse-product-properties.md) — Группирует характеристики по свойствам и вычисляет скидку выбранного варианта.
- [Параметры строки запроса](query-parameters.md) — Читает повторяющиеся параметры и значения из URL.
- [Адаптивная высота промобаннера](responsive-height.md) — Выведите изображение категории с текстом и ссылкой. Баннер заполняет ширину контейнера, а его высота меняется вместе с шириной экрана. Если текст занимает несколько строк, баннер остаётся достаточно высоким, чтобы текст не обрезался.
- [Округление числа](round-number.md) — Преобразует строку с десятичной запятой и округляет значение.
- [Элементы на краях строк](row-edges.md) — Отмечает первый и последний элемент каждой строки переносимой сетки.
- [Дата статьи с русским названием месяца](russian-month.md) — Выводит дату статьи в формате «25 февраля 2026».
