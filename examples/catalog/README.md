# Каталог

[На главную](../../README.md) · [Как использовать примеры](../../docs/usage.md)

- [Фильтр цены без перезагрузки](ajax-filter.md) — Отправляет границы цены и заменяет список товаров ответом категории.
- [Автоматическая подгрузка страниц](infinite-scroll.md) — Подгружает следующую страницу, когда ссылка попадает в область просмотра. При ошибке покупатель может повторить загрузку вручную.
- [Кнопка «Показать ещё»](load-more.md) — Добавляет товары следующей страницы, сохраняя обычную ссылку на неё.
- [Сетка товаров категории](product-grid.md) — Выведите карточки товаров с изображением, ценой и наличием. Карточки одной строки имеют одинаковую высоту, а блок цены остаётся у нижнего края карточки, даже если названия товаров разной длины.
- [Сброс фильтров категории](reset-filter.md) — Убирает выбранные фильтры и возвращает исходный список категории.
- [Сортировка и размер страницы](sort-and-page-size.md) — Отправляет порядок сортировки и количество товаров на странице.
- [Сортировка с сохранением фильтров](sort-preserve-filters.md) — Меняйте порядок товаров, не теряя выбранные характеристики, значения свойств, диапазоны и поиск.
- [Сетка подкатегорий с изображениями](subcategory-grid.md) — Выводит дочерние категории и их изображения меню.
