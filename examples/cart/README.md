# Корзина

[На главную](../../README.md) · [Как использовать примеры](../../docs/usage.md)

- [Добавление товара в корзину](add-product.md) — Добавляет выбранный вариант товара без перезагрузки страницы.
- [Уведомление о добавлении товара](added-notice.md) — После успешного добавления показывает название товара и позволяет закрыть сообщение.
- [Корзина через HTTP](cart-api.md) — Добавляет или удаляет позицию с помощью HTTP-запроса без common.js.
- [Очистка корзины](clear-cart.md) — Очищает корзину и показывает пустое состояние после обновления.
- [Промокод в корзине](coupon.md) — Применяет или удаляет промокод и показывает сообщения корзины.
- [Сумма до порога доставки](delivery-threshold.md) — Покажите покупателю, сколько осталось до установленного в магазине порога стоимости заказа. При изменении корзины индикатор обновляется без перезагрузки.
- [Шаблон корзины с Template](lodash-cart-template.md) — Рендерит список позиций при обновлении корзины.
- [Сумма и счётчик корзины](summary.md) — Показывает количество товаров и сумму и обновляет их после действий с корзиной.
- [Изменение количества и удаление позиции](update-quantity.md) — Позволяет изменить количество позиции корзины и удалить её.
