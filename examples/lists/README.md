# Избранное и сравнение

[На главную](../../README.md) · [Как использовать примеры](../../docs/usage.md)

- [Таблица сравнения товаров](comparison.md) — Показывает свойства товаров, удаляет позицию и скрывает одинаковые строки.
- [Кнопка избранного и счётчик](favorites-button.md) — Добавляет товар в избранное и показывает число сохранённых товаров.
- [Список избранных товаров](favorites-list.md) — Выводит товары из избранного и обновляет список после удаления.
- [Ранее просмотренные товары](recently-viewed.md) — Показывает товары в порядке просмотра, кроме текущего товара.
